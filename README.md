# Dr. Pritom Ghosh — Medical Portfolio

A polished, responsive professional portfolio for Dr. Pritom Ghosh, MBBS (DU), medical intern and aspiring orthopaedic surgeon.

## Highlights

- Responsive editorial design for mobile, tablet, and desktop
- Accessible navigation and reduced-motion support
- Light/dark color themes with saved preference
- SEO and social sharing metadata
- Clinical experience, research, credentials, and direct contact sections
- No build step or framework dependency

## Local preview

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173` from this directory.

## Deployment

This is a static site. Deploy the repository root to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static host.
